# 慢慢有钱 · 财务目标计算器

独立中文静态网页，用当前年龄、初始资金、每月或每年固定投入、财务目标、预计年化收益及通胀，计算首次达标的年龄。

默认：30 岁、初始 100 万人民币、每月末投入 1 万、目标 500 万、名义年化收益 5%、通胀 2%。

## 计算约定

- 名义年化收益 r 的有效月增长因子为 `(1+r)^(1/12)`；先增长，再在月末投入。年度投入仅发生在每满 12 个月的年末。
- 未来金额目标固定；今天购买力目标为 `目标 × (1+通胀)^年数`。
- 每月检查是否达标，最多计算 100 年；已达标为 0 个月，未达标明确显示，不假设能够达标。
- 固定名义投入，不随通胀增长；不计税费、提款、市场波动和退休后的资金消耗。它是财务目标情景计算器，不是退休资金持续性模拟。
- 按满月显示年龄；展示金额四舍五入，计算使用未舍入数值。

## 本地运行与验证

直接打开 `index.html`，或使用任意静态服务器。无需安装依赖。

```sh
node --test tests/*.test.cjs
node --check calculator.js
node --check app.js
```

GitHub Pages 从 `main` 分支根目录发布。发布文件：`index.html`、`style.css`、`calculator.js`、`app.js`、`.nojekyll`。
